# Lithium Technologies (Khoros)

> Lithium Technologies is the online-community and social-customer-engagement software company founded in 2001 that pioneered brand-hosted community forums, gamification and reputation systems for enterprise customer support. Acquired by Vista Equity Partners in 2017 and merged with Spredfast in 2019, the combined business now operates as Khoros (khoros.ai). Its developer surface spans five products: Khoros Communities Classic (REST v1/v2 + LiQL), Khoros Communities Aurora (GraphQL), Khoros Care, Khoros Marketing (the Spredfast-lineage APIs on api.spredfast.com), and Khoros Flow.

Generated by the API Evangelist enrichment pipeline on 2026-07-19. Khoros does not publish an llms.txt of its own (developer.khoros.com/llms.txt returns 404), and publishes no OpenAPI for any surface. Portions of the developer documentation are gated behind the Khoros community login.

## APIs

- [Khoros Marketing Conversations API](https://developer.khoros.com/khorosmarketingdevdocs/reference): Conversations, Publishing, Analytics Reporting and Notification. Base URL `https://api.spredfast.com/v2`. 3-legged OAuth 2.0 with Bearer tokens valid for two years.
- [Khoros Care APIs](https://developer.khoros.com/khoroscaredevdocs/reference): Automation Framework (events), Author and Conversation, CRM Gateway, Analytics, Brand Messenger. HTTP Basic, plus a 90-day refreshable bearer token for the Automation Framework.
- [Khoros Communities Classic APIs](https://developer.khoros.com/khoroscommunitydevdocs/reference/khoros-communities-platform-apis): REST v1 and v2 plus LiQL, the SQL-like community query language.
- [Khoros Communities Aurora GraphQL API](https://developer.khoros.com/khorosauroradevdocs/graphql): GraphQL API for the next-generation community platform; credentials issued via API Apps.
- [Khoros Flow APIs](https://developer.khoros.com/khoros-flow/reference/getting-started-flow-socket): Flow Socket (WSS), Flow REST and Flow Management APIs for conversational bots.
